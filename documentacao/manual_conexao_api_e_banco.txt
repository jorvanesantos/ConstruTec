2. PASSO 1: CONFIGURAÇÃO DO BANCO DE DADOS (MySQL)
================================================================================

Antes de conectar a API, o banco MySQL precisa existir no seu computador 
ou no seu servidor de hospedagem.

1. Abra o terminal do MySQL (ou ferramenta como MySQL Workbench / DBeaver / phpMyAdmin).

2. Execute o script contido em /database/create_database.sql:

   CREATE DATABASE IF NOT EXISTS construtec_db
     CHARACTER SET utf8mb4
     COLLATE utf8mb4_unicode_ci;

3. Execute o script de criação de tabelas contido em /database/create_tables.sql:
   Este arquivo cria as tabelas:
   - tipos_obra
   - materiais
   - localizacoes
   - orcamentos
   - orcamento_materiais

4. (Opcional) Popule os dados iniciais de materiais e regiões rodando:
   /database/insert_data.sql

3. PASSO 2: CONECTAR A API NODE.JS (server.ts) AO BANCO DE DADOS
================================================================================

Se você está usando o servidor padrão do projeto (server.ts em Node.js/TypeScript):

A) INSTALAR O DRIVER DO MYSQL:
No terminal da raiz do projeto, instale o driver 'mysql2':
   npm install mysql2
   npm install -D @types/node

B) CONFIGURAR O ARQUIVO .env:
Crie ou edite o arquivo /.env na raiz do projeto e adicione:

DB_HOST=localhost
DB_PORT=3306
DB_NAME=construtec_db
DB_USER=root
DB_PASSWORD=sua_senha_aqui

C) CÓDIGO PARA ADICIONAR NO ARQUIVO /server.ts:

No topo do arquivo /server.ts, adicione a importação do mysql2:

--------------------------------------------------------------------------------
// [NOVO] Adicionar nos imports no início de /server.ts:
import mysql from 'mysql2/promise';

// [NOVO] Criar o Pool de Conexão com o Banco de Dados MySQL:
const pool = mysql.createPool({
  host: process.env.DB_HOST || 'localhost',
  port: Number(process.env.DB_PORT) || 3306,
  user: process.env.DB_USER || 'root',
  password: process.env.DB_PASSWORD || 'sua_senha_aqui',
  database: process.env.DB_NAME || 'construtec_db',
  waitForConnections: true,
  connectionLimit: 10,
  queueLimit: 0
});

// Testar se a conexão com o banco está ativa:
pool.getConnection()
  .then((conn) => {
    console.log('✅ Conexão com o Banco de Dados MySQL realizada com sucesso!');
    conn.release();
  })
  .catch((err) => {
    console.error('❌ Erro ao conectar no Banco de Dados MySQL:', err.message);
  });
--------------------------------------------------------------------------------

D) SUBSTITUIR AS ROTAS EM /server.ts PARA SALVAR E LER DO BANCO REAL:

Substitua as rotas /api/orcamentos por estas que executam comandos SQL reais:

--------------------------------------------------------------------------------
// 1. ROTA PARA LISTAR ORÇAMENTOS SALVOS DO BANCO DE DADOS:
app.get('/api/orcamentos', async (req: Request, res: Response) => {
  try {
    const [rows]: any = await pool.query(`
      SELECT o.*, l.nome_estado, l.uf, l.multiplicador_preco
      FROM orcamentos o
      LEFT JOIN localizacoes l ON o.localizacao_id = l.id
      ORDER BY o.data_criacao DESC
    `);
    res.json(rows);
  } catch (error: any) {
    res.status(500).json({ error: 'Erro ao buscar orçamentos no banco', details: error.message });
  }
});

// 2. ROTA PARA SALVAR UM NOVO ORÇAMENTO NO BANCO DE DADOS:
app.post('/api/orcamentos', async (req: Request, res: Response) => {
  try {
    const { title, clientName, workType, calculationResult, location, notes } = req.body;

    const query = `
      INSERT INTO orcamentos (
        titulo, 
        nome_cliente, 
        tipo_obra, 
        area_m2, 
        volume_m3, 
        margem_desperdicio, 
        custo_total_estimado, 
        resultado_json, 
        status
      ) VALUES (?, ?, ?, ?, ?, ?, ?, ?, 'rascunho')
    `;

    const values = [
      title,
      clientName || null,
      workType,
      calculationResult.area || null,
      calculationResult.volume || null,
      calculationResult.wastePercentage || 10,
      calculationResult.totalEstimatedCost,
      JSON.stringify(calculationResult)
    ];

    const [result]: any = await pool.query(query, values);

    res.status(201).json({
      id: result.insertId,
      message: 'Orçamento gravado no banco de dados com sucesso!'
    });
  } catch (error: any) {
    res.status(500).json({ error: 'Erro ao salvar orçamento no banco', details: error.message });
  }
});

// 3. ROTA PARA EXCLUIR UM ORÇAMENTO DO BANCO DE DADOS:
app.delete('/api/orcamentos/:id', async (req: Request, res: Response) => {
  try {
    const { id } = req.params;
    await pool.query('DELETE FROM orcamentos WHERE id = ?', [id]);
    res.json({ message: 'Orçamento excluído com sucesso!' });
  } catch (error: any) {
    res.status(500).json({ error: 'Erro ao excluir orçamento', details: error.message });
  }
});

4. PASSO 3: CONECTAR A API JAVA SPRING BOOT (backend/) AO BANCO DE DADOS
================================================================================

O projeto já contém um backend corporativo completo em Java Spring Boot na pasta
/backend. Caso prefira rodar este backend Java:

CAMINHO DO ARQUIVO:
/backend/src/main/resources/application.properties

LINHAS QUE VOCÊ DEVE ALTERAR:
Abra esse arquivo e coloque o endereço e a senha do seu MySQL:

--------------------------------------------------------------------------------
server.port=8080

# URL de Conexão com o MySQL:
spring.datasource.url=jdbc:mysql://localhost:3306/construtec_db?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=America/Sao_Paulo

# Usuário e Senha do seu MySQL:
spring.datasource.username=root
spring.datasource.password=sua_senha_aqui

spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver

# O Hibernate atualiza as tabelas automaticamente:
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
--------------------------------------------------------------------------------

COMO EXECUTAR O BACKEND JAVA:
No terminal, entre na pasta /backend e execute:
   cd backend
   ./mvnw spring-boot:run
   (ou 'mvn spring-boot:run' no Windows)

O backend subirá em: http://localhost:8080/api/

5. PASSO 4: CONECTAR O FRONTEND (REACT) À SUA API
================================================================================

O frontend React faz as requisições HTTP usando o comando nativo 'fetch' ou 'axios'.

A) SE A SUA API ESTIVER RODANDO NO MESMO SERVIDOR (Node/Express):
Todas as chamadas já apontam para caminhos relativos como:
   fetch('/api/orcamentos')
   fetch('/api/calculos')

B) SE A SUA API ESTIVER EM OUTRO ENDEREÇO (ex: Spring Boot na porta 8080 ou servidor na nuvem):

1. Crie um arquivo central de configuração da API:
   CAMINHO DO NOVO ARQUIVO: /src/services/apiConfig.ts

   Código para colocar nele:
--------------------------------------------------------------------------------
   // /src/services/apiConfig.ts
   export const API_BASE_URL = import.meta.env.VITE_API_URL || 'http://localhost:8080/api';
--------------------------------------------------------------------------------

2. No arquivo /.env, declare o endereço da sua API:
   VITE_API_URL=http://localhost:8080/api

3. Exemplo de como usar no código React (ex: em /src/components/Calculator.tsx):

--------------------------------------------------------------------------------
import { API_BASE_URL } from '../services/apiConfig';

// Função para salvar orçamento na sua API:
async function salvarOrcamentoNaApi(dadosOrcamento: any) {
  try {
    const resposta = await fetch(`${API_BASE_URL}/orcamentos`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        // Se sua API exigir autenticação / Token JWT:
        // 'Authorization': `Bearer ${localStorage.getItem('token')}`
      },
      body: JSON.stringify(dadosOrcamento)
    });

    if (!resposta.ok) {
      throw new Error(`Erro na API: ${resposta.statusText}`);
    }

    const resultado = await resposta.json();
    console.log('Orçamento salvo com sucesso!', resultado);
    return resultado;
  } catch (erro) {
    console.error('Falha ao comunicar com a API:', erro);
    throw erro;
  }
}
--------------------------------------------------------------------------------

6. PASSO 5: COMO CONECTAR UMA API EXTERNA (EX: CEP OU PREÇOS)
================================================================================

Se você quiser conectar uma API externa (por exemplo, a API do ViaCEP para preencher
a cidade e estado automaticamente quando o usuário digitar o CEP da obra):

CAMINHO DO ARQUIVO:
/src/services/cepService.ts

CÓDIGO PRONTO:
--------------------------------------------------------------------------------
// /src/services/cepService.ts
export interface EnderecoViaCep {
  cep: string;
  logradouro: string;
  bairro: string;
  localidade: string; // Cidade
  uf: string;         // Estado
  erro?: boolean;
}

export async function buscarCep(cepLimpo: string): Promise<EnderecoViaCep | null> {
  try {
    const cepNumeros = cepLimpo.replace(/\D/g, '');
    if (cepNumeros.length !== 8) {
      throw new Error('CEP deve conter 8 dígitos.');
    }

    const response = await fetch(`https://viacep.com.br/ws/${cepNumeros}/json/`);
    const data = await response.json();

    if (data.erro) {
      return null;
    }

    return data;
  } catch (error) {
    console.error('Erro ao consultar API de CEP:', error);
    return null;
  }
}

7. TESTANDO A CONEXÃO E RESOLUÇÃO DE ERROS COMUNS
================================================================================

COMO TESTAR SE A SUA API ESTÁ FUNCIONANDO:

1. Pelo terminal com cURL:
   curl -X GET http://localhost:3000/api/health

   Resposta esperada:
   {"status":"ok"}

2. Testar busca de orçamentos:
   curl -X GET http://localhost:3000/api/orcamentos

3. Testar via navegador:
   Abra no seu navegador: http://localhost:3000/api/orcamentos


PRINCIPAIS ERROS E COMO RESOLVER:

1. ERRO: "ECONNREFUSED 127.0.0.1:3306"
   Causa: O serviço do MySQL está desligado ou o IP/porta estão incorretos.
   Solução: Inicie o serviço do MySQL no seu computador (Services no Windows,
   ou 'sudo systemctl start mysql' no Linux, ou via Docker).

2. ERRO: "Access denied for user 'root'@'localhost'"
   Causa: A senha do MySQL informada no .env ou application.properties está incorreta.
   Solução: Verifique a senha de root do seu MySQL e ajuste o arquivo .env.

3. ERRO DE CORS NO FRONTEND: "Access-Control-Allow-Origin"
   Causa: O Frontend está em uma porta (ex: 3000) e a API em outra (ex: 8080).
   Solução: No backend Java, adicione a anotação @CrossOrigin("*") no Controller,
   ou no Express adicione:
   app.use(cors({ origin: '*' }));
